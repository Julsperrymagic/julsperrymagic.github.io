CASE 01 · EXPERIENCIA CIUDADANA + DATOS

Clara + Métrica Nacional de Transparencia

Una experiencia digital para convertir una medición compleja en una consulta comprensible, comparativa y accionable.

Desafío

Una métrica nacional puede ser técnicamente correcta y aun así resultar difícil de explorar para una persona no especializada.

Solución

Se diseñó un portal guiado por Clara: explicación contextual, filtros, mapa, resultados, buenas prácticas y descargas dentro de una misma experiencia.

Valor

Reduce la distancia entre el dato institucional y su lectura ciudadana; permite entender, comparar y preparar información sin navegar entre herramientas separadas.

Arquitectura / implementación
Arquitectura

Frontend web modular con filtros, componentes de visualización, navegación guiada y generación de vistas de resultados.

Interacción

Experiencia por texto y componentes guiados; el diseño contempla conversación por voz en entorno HTTPS, exploración sin asistente y reportes descargables.

Diseño de información

Jerarquía nacional → entidad → sujeto obligado, lectura por componentes, comparativos y semáforos para facilitar interpretación.

CASE 02 · DATOS + SERVICIO PÚBLICO

CONECTA

Sistema de registro, trazabilidad e inteligencia operativa para convertir la atención ciudadana en evidencia útil para gestionar.

Proyecto preparado para concursar al Premio Nacional de Administración Pública 2026
Desafío

La atención por distintos canales genera datos dispersos, criterios distintos y poca visibilidad sobre cargas de trabajo, temas y resultados.

Solución

CONECTA estandariza el registro, clasifica cada atención y consolida el seguimiento en una estructura común.

Valor

Convierte operación cotidiana en tableros, tendencias y evidencia para supervisión, mejora del servicio y rendición de cuentas.

Arquitectura / implementación
Modelo de datos

Campos normalizados para canal, usuario, entidad, servicio, materia, nivel de atención, gestión, sujeto obligado y cierre de consulta.

Automatización

Flujos con formularios, hojas de cálculo y Apps Script para reducir captura manual, ordenar registros y alimentar reportes.

Analítica

Indicadores por temporalidad, materia, canal, perfil de usuario, carga de trabajo y niveles de atención con lectura ejecutiva.

CASE 03 · PYTHON + COMERCIO + APIs

POS La Joya

Un ecosistema para conectar mostrador, inventario, compras, caja, reportes y comercio electrónico en una sola lógica operativa.

Desafío

Una refaccionaria necesita vender rápido sin perder control sobre existencias, costos, devoluciones, caja y movimientos entre el local y la web.

Solución

Se construyó un POS de escritorio con módulos para venta, inventario, compras, etiquetas, reembolsos, gastos, dashboard y sincronización.

Valor

El sistema reduce dependencias de registros separados y conecta la operación física con el canal digital y el flujo de facturación.

Arquitectura / implementación
Aplicación

Python + Tkinter para interfaz de escritorio y reglas operativas; SQLite para persistencia local y trazabilidad.

Integración

REST API con WooCommerce/WordPress para sincronización de catálogo, inventario y procesos del canal web.

Módulos

Venta, descuentos, formas de pago, stock, compras, margen, etiquetas, devoluciones, caja, gastos, cierres, indicadores y sincronización.

Principio de trabajo

La tecnología es el medio. La mejora es el producto.

Una interfaz atractiva puede llamar la atención; un sistema útil debe además reducir fricción, ordenar información, proteger datos, soportar decisiones y seguir funcionando cuando aparecen excepciones.
